# Deep Learning Experiments & Projects

A collection of deep learning implementations, neural network architectures, and practical machine learning projects built with Python and TensorFlow / Keras.

---

## 📂 Repository Contents

| Project / Notebook | Description | Framework / Key Tools |
| :--- | :--- | :--- |
| [**handwritten_digit_recognition_model/**](./handwritten_digit_recognition_model/) | MNIST handwritten digit classification comparing ANN (~98.1%) & CNN (~99.5%), saved `.keras` model, and an interactive **Streamlit drawing canvas web app** (`app.py`). | TensorFlow / Keras, Streamlit, CNN |
| [**CNN.ipynb**](./CNN.ipynb) | End-to-end convolutional neural network training notebook for image classification. | TensorFlow / Keras |
| [**iris.ipynb**](./iris.ipynb) | Multi-class classification using neural networks on the classic Iris dataset. | Scikit-Learn, Keras |
| [**basics.ipynb**](./basics.ipynb) | Fundamental deep learning concepts, perceptrons, and feedforward networks. | NumPy, Keras |

---

## 🛠️ Tech Stack & Requirements

- **Python**: 3.9+
- **Deep Learning**: TensorFlow, Keras
- **Web App**: Streamlit, Streamlit-Drawable-Canvas
- **Data & Visualization**: NumPy, Pandas, Matplotlib, Plotly, Scikit-Learn

### Installation
```bash
pip install tensorflow numpy pandas matplotlib scikit-learn streamlit streamlit-drawable-canvas plotly jupyter
```

## 🚀 Quick Start

Clone the repository and open any notebook in Jupyter or your favorite IDE:
```bash
git clone https://github.com/mudit-1711/Deep_learning.git
cd Deep_learning
jupyter notebook
```
